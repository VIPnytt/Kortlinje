# 💡 Kortlinje

IKEA Kortlinje teardown and reverse engineering.

The goal of this project is to transform it into a fully functional open-source alarm-clock display, with temperature and humidity reading, a functional web interface and Wi-Fi syncronized date/time.

At the moment, the project is in its early stages, and the main focus is on understanding the hardware and software of the Kortlinje device. Contributions are welcome!
